STM32 lab programs

Ten programs for the NUCLEO-L432KC from the Embedded Processors labs at UESTC: timers and PWM, an accelerometer over SPI and a temperature sensor over I2C.

Course
Embedded Processors, UESTC (2026); module mark 82%
Board
NUCLEO-L432KC (Arm Cortex-M4F)
Tools
C++, Mbed OS 6, Keil Studio
Result
About 40 times lower sensor current using shutdown mode with interrupt-triggered readings

The programs

Keil Studio Cloud closed when Arm ended Mbed, taking the original projects with it, so these were recovered from the code printed in my lab reports.

LabTaskWhat it does
22.4A 1 kHz PWM output whose duty cycle a timer interrupt switches between 70% and 30% every two seconds, with an LED showing which.
32Sets up the SPI bus for the ADXL345 accelerometer at a 2 MHz clock.
33Reads all three axes from the ADXL345.
34Drives LEDs from the accelerometer readings.
35Eight LEDs show which way, and how far, the board is tilted on each axis.
41Reads the TMP102 temperature sensor in continuous conversion mode.
42Averages readings to reduce noise.
43Puts the TMP102 into shutdown mode.
44Compares the current drawn in continuous and shutdown modes.
45Takes a one-shot reading each time a push-button interrupt fires.

Measuring the current showed that keeping the sensor in shutdown mode and only waking it for a one-shot reading when needed cut its current by about 40 times.

Looking back

Recovering the code meant reading it again, and two things stood out:

  • In Lab 4 Task 5 the program waits 20 ms after starting a one-shot conversion, but the TMP102 datasheet gives a typical conversion time of 26 ms, so a reading can return the previous result. Waiting 35 ms, or polling the one-shot bit, fixes it.
  • Temperatures between 0 and -1 °C would print without their minus sign, because the whole-number part is printed after a cast to int, which rounds towards zero.
